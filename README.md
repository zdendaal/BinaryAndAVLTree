# Implementation of AVL and binary tree
Project is written in .NET 10.0.
This repository contains:
  - Binary tree using 1D array of generic numeric type.
  - AVL tree using referencing nodes among each other. Suitable for storing big data by value, during actions requiring manipulation with nodes, it reconnects them properly during balancing and deleting phase.
Implementations can be found in [AVLtree](AVLtree/) folder.
Tests are separated to folders [AVLTreeTest](AVlTreeTest/) and [BinaryArrayTreeTests](BinaryArrayTreeTests/).
